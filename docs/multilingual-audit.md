# 多语言审计（2026-09-14）

## 结论
当前实现是 Google 整页机器翻译，已覆盖项目内两种 HTML 页面（首页与 404），语言菜单包含 27 个选项，可以连续切换。但不等同于所有内容、所有状态均完整本地化，也不是 27 套独立的多语言 SEO 页面。

## 范围与证据
- 源码路由只有首页和 404；vercel.json 中其他入口重定向至首页的对应区域。未部署或在线核验这些重定向。
- 在本地真实浏览器的 404 页逐项检查了 26 种非英语语言，均观察到主标题产生对应译文；英文恢复也通过。覆盖 de, es, fr, it, pl, pt, ro, sv, nl, da, fi, el, cs, hu, bg, sk, hr, sl, lt, lv, et, ga, mt, zh-CN, ja, ko。
- 首页抽查中文、德语、韩语：正文区域可以翻译。中文下 FAQ 答案、翻页后商品及打开后的 QC 弹窗最终产生译文，存在异步延迟。
- 韩语下选择 Hoodies 后显示 8 条正确类别商品，筛选值未被译名破坏。
- 404 刷新保持韩语；从 404 返回首页后自动恢复韩语。
- 快速连续选择中文、日语、英文后，标题恢复英文，lang=en，无残留忙碌状态，分类保持 Hoodies。
- 验证期间未发现页面控制台错误。脚本语法、商品数据、生产构建和 diff 检查通过。

## 本次修复
- 提取共享 SiteHeader，首页与 404 使用同一语言入口。
- 翻译挂载不再强制依赖 footer；无 canonical 的页面也能生成失败备用链接，并保留当前路径。
- 增加站内语言偏好保存，存储受限时回退到 Cookie；回到英文会取消待完成的翻译初始化并重新载入。
- 搜索同时匹配英文原名和已经显示的译名。尚未翻译的隐藏商品仍只能按已有文字搜索。
- 页码改为数字形式（例如 2 / 10），避免动态更新后残留英文。

## 尚有限制
- 页面 title、SEO description、结构化数据仍为英文；没有独立语言 URL 与 hreflang。
- 部分 aria-label、菜单本身、加载/错误提示以及短暂复制提示未实现完整的本地词典翻译。
- 动态或原先隐藏内容需要显示后等待服务翻译，短暂提示可能来不及翻译。
- 图片内文字、品牌及款式专名不保证翻译；外部购买、源站与 QC 图片链接不受本站控制。
- 服务不可访问时无法保证翻译可用，脚本加载失败有提示与备用入口。本次未人为阻断服务验证失败路径，也没有对每页每个句子做 27 种语言的人工质量校对。

如验收标准是“所有网页文字立即、稳定地随意切换”，仍需完整本地翻译词典（包含动态消息与无障碍属性）及相应语言路由，不能只依靠当前机器翻译组件。
